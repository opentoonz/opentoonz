Cel Color Keep

Keep selected cel colors and make the rest transparent. Add the effect from the Matte category and connect the image to Source. A new effect keeps black.

Choose colors

  1. Set Enabled Colors to the number of colors to keep, from 0 to 100.
  2. Choose an entry from the Colors list. Each entry has its own swatch.
  3. Use the normal color editor or picker to choose that entry's color. Temporarily disable the effect when sampling colors from its source image.
  4. Repeat for the other enabled entries. Duplicate colors are allowed.

Entries beyond Enabled Colors are marked inactive. Lowering the count never erases their values or animation. Set the count to 0 for transparent output. The list selection only chooses which color to edit.

Animation and reuse

Use the key button to animate each color and the enabled count. An animated count rounds to the nearest whole number; half values round upward. All 100 entries are saved in scenes and effect presets and copied with the effect. Colors can be exposed as individual macro controls. Use the Function Editor's RGB channels for precise numeric values beyond the color picker's swatches.

Matching and transparency

Selected colors preserve their original RGB and transparency. Rejected colors become fully transparent. A color's alpha control does not participate in the selection. Partial coverage is accounted for when comparing colors, so a red cel edge can remain red while preserving its original opacity.

For 8-bit and 16-bit images, the selected RGB is converted to the source's channel precision before comparison. Float images use a fixed tolerance of 0.0001 per RGB channel. Finite float colors outside the normal display range are supported. Matching uses display RGB; the renderer handles conversion for scenes rendered in linear color. Fully transparent and invalid pixels produce transparent output.

Exact integer matching is intended for flat cel colors. Anti-aliasing can mix neighboring colors; add those colors to the list when they should also remain.
